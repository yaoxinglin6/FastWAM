# RoboTwin 全任务阻尼参数扫描总结

## 实验设置

本实验评估两类阻尼扰动：`object_joint_damping` 和 `robot_joint_damping_scale`。`object_joint_damping` 作用于 RoboTwin 任务对象中显式调用 `apply_object_joint_damping()` 的 articulation；`robot_joint_damping_scale` 将机器人 URDF 关节阻尼按统一倍率缩放，`1.00` 为当前代码基线。

全任务扫描覆盖 50 个任务。每个任务在 clean/random 两个阶段分别使用各自归档 YAML 中前三个环境 seed，每个 seed 运行一次，policy seed 固定为 `42`。每个 task/phase/参数值单元的固定分母为 3；专家前检失败也计入失败，但不会进入策略 rollout。

本总结合并以下有效结果：`evaluate_results/robotwin/physics_sweep/all_tasks_physics_sweep_20260901_gpu0_6_max2`、`docs/experiments/2026-09-01-robotwin-all-tasks-physics-sweep/details.csv`、`evaluate_results/robotwin/physics_sweep/high_physics_sweep_20260903_gpu0_7_max2`。不使用 `joint_damping_fine_20260831_gpu0_2`，该批次因 `collision_material` 未定义导致 per-seed 结果无效。

## 总体结果

合并 clean/random 后，`object_joint_damping` 的最佳值为 `1`，总体成功率为 90.00%。`object_joint_damping` 从 `0` 扫到 `25` 后，全任务平均成功率仍保持在 86.67%-90.00%，没有出现全局失败边界。

`robot_joint_damping_scale` 的最佳值为 `1.5`，总体成功率为 93.67%。默认倍率 `1.00` 的总体成功率为 89.33%，最佳点相对基线提高 +4.34 个百分点。继续增大后退化清晰：`3` 为 82.33%，`4` 为 77.67%，`5` 降到 65.67%。

全部 6000 个固定试验槽位中，成功 5206 次，专家前检失败 553 次，专家通过但策略失败 241 次。补充明细中的专家前检失败主要包括：专家规划未达到任务成功条件 212 次、`target_pose` 缺失断言 31 次、场景对象不稳定 13 次、IndexError 3 次、LinAlgError 1 次。以上是运行时错误类别，不将其进一步归因为单一阻尼效应。

## 主要观察

- `object_joint_damping` 对全任务平均影响较小，主要因为 50 个任务中大量任务没有 articulation damping 敏感路径，或成功判据不受该扰动主导。
- `object_joint_damping` 的任务级敏感性集中在 articulation 和堆叠/容器类任务。`turn_switch`、`open_microwave` 随阻尼增大持续退化，适合用于寻找 object damping 的任务级上界。
- `robot_joint_damping_scale` 是更清晰的全局压力源。`0.5-2` 仍稳定，`3` 是偏强但基本可用的扰动，`4` 开始越界，`5` 已明显破坏全任务表现。
- clean 通常高于 random，但 `robot_joint_damping_scale=4` 附近 random 略高于 clean，说明该范围内成功率已受 seed 和具体任务结构影响，不宜解释为单调物理规律。

## 结论边界

- `object_joint_damping` 在全任务平均上没有找到失败边界；已采样的 `0-25` 均保持 86.67% 以上。
- 如果目标是任务级失败边界，`turn_switch` 和 `open_microwave` 是最干净的候选任务；两者在高 object damping 下接近或达到零成功。
- `robot_joint_damping_scale` 的可用范围建议写为 `0.5-3`；`4` 是边界外侧，`5` 是明显失效扰动。
- 每个曲线点只有三个固定环境 seed，成功率分辨率为 1/3，适合观察趋势，不用于精细置信区间估计。
- 使用的是此前筛选出的 successful seeds，因此结果衡量的是这些固定场景对阻尼变化的敏感性，不代表随机 seed 分布上的无偏成功率。
