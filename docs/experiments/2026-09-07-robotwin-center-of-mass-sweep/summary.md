# RoboTwin 全任务质心偏移扫描总结

## 实验设置

本实验评估任务对象质心偏移对策略成功率的影响，包含两类扫描：单轴质心偏移和三维球面质心偏移。单轴扫描分别改变 `center_of_mass_offset_x/y/z`；球面扫描在不同半径壳层中采样三维 offset 向量，并同时作用于 x/y/z 三个方向。

50 个任务的 clean/random 分别使用各自归档 YAML 中前三个环境 seed，每个任务、phase、质心参数和环境 seed 组合评测一次，policy seed 固定为 `42`。每个 task/phase/参数值单元的固定分母为 3；专家前检失败也计入失败，但不会进入策略 rollout。

单轴扫描结果来自 `evaluate_results/robotwin/physics_sweep/all_tasks_physics_sweep_20260901_gpu0_6_max2` 与 `docs/experiments/2026-09-01-robotwin-all-tasks-physics-sweep/details.csv`。球面扫描结果来自 `evaluate_results/robotwin/physics_sweep/center_of_mass_sphere_20260905_gpu0_7_max2`，采样定义见 `docs/experiments/2026-09-05-robotwin-center-of-mass-sphere-sweep/center_of_mass_sphere_samples.json`。

## 总体结果

单轴扫描显示，质心偏移是比恢复系数和 object damping 更强的扰动。`center_of_mass_z` 最敏感，`z=-0.03` 和 `z=0.03` 分别只有 49.33% 与 53.67%；`center_of_mass_y` 为中等敏感，`y=0.04` 降到 66.00%。`center_of_mass_x` 出现强非单调现象：`x=+-0.04` 只有 22.00%，但更大的 `+-0.05/0.10/0.15` 又恢复到 88.67%-92.67%，不适合直接解释成连续物理边界。

球面扫描共 6000 个固定试验槽位，成功 2804 次，总体成功率 46.73%。其中专家前检失败 2910 次，专家通过但策略失败 286 次。失败主要集中在 expert planning 和场景稳定性阶段，说明较大质心偏移首先会破坏任务物理可达性或初始化稳定性，而不只是降低策略 rollout 成功率。

## 主要观察

- 球面半径 `0-0.015` 仍基本可用，合并成功率为 80.75%；半径进入 `0.015-0.030` 后降到 61.58%，已经是明显扰动。
- 半径 `0.030-0.045` 后成功率跌到约三分之一，`0.060-0.080` 只有 20.25%，说明质心偏移强度与整体失败率有清楚关系。
- 单轴结果中 `center_of_mass_z` 的趋势最可解释：从 `0` 到 `+-0.03` 明显下降。`center_of_mass_y` 次之，正向 `0.04` 比负向 `-0.04` 更差。
- `center_of_mass_x` 单轴结果不应用于连续边界结论；`+-0.04` 极差但更大偏移恢复高成功率，更像参数映射、生效对象或固定 seed 的组合效应。

## 结论边界

- 三维质心偏移的可用半径建议写为 `0-0.015`；`0.015-0.030` 已明显退化，`>=0.030` 可视为强扰动区间。
- 单轴结论中，`center_of_mass_z` 是最可靠的强敏感方向，`+-0.03` 已使成功率降到 50% 左右；`center_of_mass_y` 为中等敏感方向。
- `center_of_mass_x` 存在明显非单调，不建议作为连续边界证据。若文档中引用，应明确说明需要复核参数映射和实际生效对象。
- 每个曲线点只有三个固定环境 seed，成功率分辨率为 1/3，适合观察趋势，不用于精细置信区间估计。
